## Review and approve

1. Read the first scene in the script carousel.
2. Move through the scenes with the arrows.
3. To change a line, select the narration and edit it.
4. When it's right, select **Approve script**.

Velo builds the video once you approve.

## Ask for a rewrite

1. Select **Rewrite script**.
2. In **What should change?**, describe the change (for example, "Shorter, and lead with the benefit").
3. Send it. Velo writes a new version for you to review.

## How edits work

- **Your words are used as typed:** Lines you edit are sent to Velo as "Use my wording verbatim", so they aren't reworded.
- **Narration only:** The carousel shows what the voice says. Ask in chat for changes to visuals.
- **Names that sound wrong:** Add them to your Brand Kit's pronunciations, so every video says them right. See [Brand Kit](/organize/brand-kit#set-up-pronunciation).

## FAQs

**Will Velo change the lines I edited?**

No. Edited lines are used word for word.

**Can I change the script after the video is built?**

Yes. Ask for the change in chat. See [Edit by chat and comments](/edit/edit-by-chat-and-comments).

**Does approving the script use credits?**

Yes. Approving is a message to the agent, and every message uses credits.
