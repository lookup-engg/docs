Install the Velo Companion extension in Chrome so you can record your screen with Velo.

> *Placeholder (gif): Chrome Web Store Add to Chrome, pinning Velo Companion from the puzzle-piece menu, then signing in*

## Install the extension

1. Open the Chrome Web Store and search for **Velo Companion**.
2. Select **Add to Chrome**, then **Add extension**.
3. Select the puzzle-piece icon in the Chrome toolbar.
4. Select the pin icon next to **Velo Companion**.
5. Open the extension and sign in with your Velo account.

You only install it once. After that, start recordings from **Record Screen** on the home screen.

## Update the extension

Chrome updates extensions on its own. To update right away:

1. Go to `chrome://extensions`.
2. Turn on **Developer mode** in the top-right corner.
3. Select **Update**.

To check your version, find **Velo Companion** on the same page. The version shows under its name.

## Reinstall the extension

Reinstall when recordings won't start or the extension stops responding.

1. Go to `chrome://extensions`.
2. Find **Velo Companion** and select **Remove**, then confirm.
3. Quit Chrome completely: on Mac, press `Cmd + Q`. On Windows, right-click the Chrome icon and select **Exit**.
4. Reopen Chrome and install the extension again from the Chrome Web Store.
5. Pin it and sign back in.

## FAQs

**Velo says "Install the Velo extension to record your screen." What do I do?**

Install the extension, or reinstall it if it's already there. Then select **Record Screen** again.

**Does it work in browsers other than Chrome?**

  Velo Companion is a Chrome extension.

**Do I have to sign in again after reinstalling?**

Yes. Open the extension and sign in with your Velo account.
