## Which option fits

| You have | Choose | Velo makes |
| --- | --- | --- |
| An idea | Type in the chat box, or use a template | A video built from your request. See [Start from a prompt or template](/create/start-from-a-prompt-or-template) |
| Yourself and a camera | **Record Yourself** | A produced demo from one take. See [Record Yourself](/create/record-yourself) |
| A script, no camera | **Generate with Avatar** | A presenter video. See [Generate with Avatar](/create/generate-with-avatar) |
| A product flow to show | **Record Screen** | A narrated video of your recording. See [Record your screen](/create/record-your-screen) |
| A deck or document | **Turn PDF to video** | A narrated video of your file. See [Turn a PDF into a video](/create/turn-a-pdf-into-a-video) |
| A video file | **Polish a recording** | A cleaned-up video with zooms and narration. See [Polish a recording](/create/polish-a-recording) |
| A link to a web product | **Turn URL to video** | A walkthrough recorded by Velo's Agentic Recording. See [Turn a URL into a video](/create/turn-a-url-into-a-video) |

## Attach files to any request

1. In the chat box, select **Attach**.
2. Choose up to **10** files.
3. Type your request and select **Send**.

Files can be video, audio, images, PDFs, Office files, text and fonts. See [Supported formats](/help/supported-formats).

<Tip>
Files your team uses often can live in [Asset Library](/organize/assets). Velo can suggest them in new chats, so you don't upload them again.
</Tip>

## FAQs

**Can I combine options, such as a PDF and a recording?**

Yes. Attach both to one request and tell Velo how to use each.

**What's the biggest file I can attach?**

**500 MB** per file. Video and audio can be up to **30** minutes, and documents up to **30** pages. See [Limits and file sizes](/help/limits-and-file-sizes).

**Do I have to pick an option?**

No. You can type a request and attach files. The options set up the chat for a kind of material.
