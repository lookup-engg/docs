## Before you start

- A PDF, PowerPoint (.pptx) or Word (.docx) file of up to **30** pages or slides and **500 MB**.

## Turn your file into a video

1. On the home screen, select **Turn PDF to video**.
2. Attach your file.
3. In your request, name the pages to focus on, and any to skip.
4. Answer the agent's questions, such as footage, length and theme.
5. Read the script, then select **Approve script**.

Velo builds the video. Longer files take a few minutes.

```text
Use pages 3 to 8 and skip the pricing slide. Make a 60-second overview for new customers.
```

<Note>
There's no page picker. Tell Velo which pages to use in your request.
</Note>

## FAQs

**My file has more than 30 pages. What do I do?**

Split it, or save only the pages you need as a new file. Velo shows an error that names the limit (for example, "has 34 pages. A PDF can have up to 30").

**Can I use an old .ppt file?**

Yes. Chat and the Asset Library both accept .ppt files.

**Can I add an avatar or change the voice afterward?**

Yes. See [Quick actions](/edit/quick-actions).
