## Edit layers

1. Select a block on the timeline.
2. Drag it to move it, or drag its edge to trim it.
3. To split it, move the playhead and press `S`. See [Split and crop](/edit/split-and-crop).
4. To hide a track, select its hide icon.
5. To add a layer, select **+**. See [Add text, shapes and media](/edit/add-text-shapes-and-media).

## Keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Play or pause | `Space` |
| Undo | `⌘Z` |
| Redo | `⌘⇧Z` or `⌘Y` |
| Duplicate | `⌘D` |
| Copy, cut, paste | `⌘C`, `⌘X`, `⌘V` |
| Delete | `Delete` |
| Split at the playhead | `S` |
| Split every clip at the playhead | `Shift+S` |
| Nudge 1 px | Arrow keys |
| Nudge 10 px | `Shift` + arrow keys |

On Windows, use `Ctrl` in place of `⌘`.

## Limits

- **Undo:** The AI Editor keeps your last **50** steps.

## FAQs

**Can I undo a change the agent made?**

Not with `⌘Z`. Restore an earlier version instead. See [Version history](/edit/version-history).

**Can I ask Velo to change timing instead?**

Yes. Comment on the moment and describe the change. See [Edit by chat and comments](/edit/edit-by-chat-and-comments).

**How do I move several blocks at once?**

  Select them together, then drag.
