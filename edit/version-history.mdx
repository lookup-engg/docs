## Restore an earlier version

1. In the header, select **Version history**.
2. Filter the list to **agent edits**, **editor edits** or the **initial version**, if you like.
3. Select a version to preview it.
4. Select **Restore this version**.

Your current version stays saved in the history, so you can switch back.

## Render or download an older version

1. In **Version history**, select the older version.
2. Select the render button that appears.
3. Download or share it once it renders.

This leaves your current version as it is.

## Good to know

- **Not mid-edit:** You can't restore while the agent is editing. You'll see **Wait for the agent to finish editing.**
- **Failed restores are safe:** If a restore fails, your current work is kept.

## FAQs

**Does restoring delete my newer versions?**

No. Newer versions stay in the history.

**Why can't I restore right now?**

The agent is still working. Wait for it to finish, or stop it, then restore.

**Can I compare two versions side by side?**

No. Preview each version in turn.
