## FAQs

**Will an edit change parts I didn't mention?**

No. Edits touch only what you asked for.

**Can I undo an agent edit?**

Yes. Restore an earlier version in [Version history](/edit/version-history).

**Do edits use credits?**

Yes, chat edits, comments and quick actions do.
