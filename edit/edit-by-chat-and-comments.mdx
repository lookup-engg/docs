## Edit in chat

1. Open the video's chat.
2. Type the change (for example, "Make the intro shorter").
3. Send it, and play the preview when Velo is done.

## Comment on a moment

1. In the preview, select **Comment**, or press `C`.
2. Select a spot on the video, or select or drag across part of the timeline.
3. Type what you want (for example, "Zoom in on the pricing table").
4. Select **Ask agent to fix**.

Velo gets the exact moment and spot with your comment, shown as a timestamp like **@0:12**.

<Tip>
For several changes, leave comments on the timeline first, then send them together.
</Tip>

## What you can ask for

- **Timing and pacing:** Shorten a scene, sync narration to a highlight.
- **Visuals:** Add a zoom, remove an object from the screen, recreate typing.
- **Privacy:** Blur details or replace a name. See [Hide private details](/edit/hide-private-details).
- **Intros and outros:** Rebuild them from a screenshot, a reference video or a brand guidelines file.
- **Pronunciation in one video:** Ask Velo to fix how a word is said in this video only.

```text
Restyle this video to match the attached reference. Keep my script, scenes, voiceover and length. Change the look to match the reference: background, colors, typography, motion, effects and transitions. Don't copy the reference's words or logo.
```

## FAQs

**Will Velo change parts I didn't mention?**

No. Edits touch only what you asked for.

**Can I undo an agent edit?**

Yes. Restore an earlier version. See [Version history](/edit/version-history).

**Does every edit use credits?**

Yes. Each chat request or comment is a new agent run.
