Check which files each part of Velo accepts before you upload.

## By upload area

| Type | Chat | AI Editor (Assets panel) | Asset Library |
| --- | --- | --- | --- |
| Video: MP4, MOV | Yes | Yes | Yes |
| Audio: MP3, WAV, M4A, AAC, OGG | Yes | Yes | Yes |
| Images: PNG, JPG, WEBP, GIF, SVG | Yes | Yes | Yes |
| Documents: PDF, DOCX, PPTX, XLSX, CSV, TXT, MD | Yes | No | Yes |
| Old Office files: PPT, XLS | Yes  | No | No |
| HTML | No | No | Yes |
| Fonts: TTF, OTF, WOFF, WOFF2 | Yes | No | No |

## Other uploads

- **Brand Kit fonts:** Font files up to **2 MB**.
- **Intro and outro:** H.264 MP4 or MOV, up to **30** seconds.
- **Custom thumbnails:** PNG or JPEG, up to **5 MB**.

<Tip>
Have an old .ppt or .xls file? Save it as .pptx, .xlsx or PDF to use it in the Asset Library.
</Tip>
