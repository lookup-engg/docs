Something not working? Troubleshoot common issues here: find the message you see below. Most fixes take a minute.

## Recording

**"Install the Velo extension to record your screen."**

1. Install the [Velo Companion extension](/create/velo-companion-extension) and sign in.
2. If it's installed, reinstall it and restart Chrome.
3. Select **Record Screen** again.

**"That recording is taking too long to process. Please try again."**

1. Try again.
2. If it happens again, record a shorter take.
3. Still stuck? Contact support.

**"We couldn't find that recording in this workspace."**

1. Switch to the workspace you recorded in.
2. Or record again in the workspace you're using.

## The agent and rendering

**The agent stopped before it finished.**

Your credits ran low. Add credits, then ask the agent to continue. Your work so far is kept. See [When you run out of credits](/plans-and-account/when-you-run-out-of-credits).

**A video seems stuck rendering.**

A single agent run stops after **90** minutes. If it's been longer, ask the agent to try again.

**"Wait for the agent to finish editing."**

You tried to restore a version while the agent was working. Wait for it to finish, or stop it, then restore. See [Version history](/edit/version-history).

**"Render the video before choosing a thumbnail frame."**

Select **Export** to render the video, then choose the frame. See [Custom thumbnails](/share/custom-thumbnails).

## Plans and limits

**"You've used your avatar face for this billing cycle. Upgrade for more."**

Free includes one avatar face per billing cycle. Wait for the next cycle, or upgrade. See [Plans and pricing](/plans-and-account/plans-and-pricing).

**"To create a brand kit, please upgrade to the Velo Pro or Ultra plan."**

Your workspace was created with a personal email, so the Brand Kit needs Pro or Ultra. Ask your workspace owner to upgrade.

**An invite failed.**

Either all seats are taken (**seat limit reached**), or the invite expired after **7** days. Free a seat or upgrade, then send a new invite. See [Workspace, members and roles](/plans-and-account/workspace-members-and-roles).

**An upload was rejected.**

The error names the limit you hit. Files can be up to **500 MB**, video and audio up to **30** minutes, and documents up to **30** pages. Trim or split the file, then upload again. See [Limits and file sizes](/help/limits-and-file-sizes).

## Still stuck?

Contact us with the message you see and the video's link. Use the chat in the corner, or email support@usevelo.ai.
