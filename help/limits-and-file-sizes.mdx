**Plans:** Free, Pro, Ultra · **Uses credits:** No

Check every Velo limit in one place before you upload or set something up.

## Uploads

| Limit | Value |
| --- | --- |
| File size | Up to **500 MB** per file |
| Video and audio length | Up to **30** minutes |
| PDF, PowerPoint and Word | Up to **30** pages or slides |
| Files per message | Up to **10** |
| Brand Kit font files | Up to **2 MB** |
| Intro or outro upload | H.264 MP4 or MOV, up to **30** seconds  |
| Custom thumbnail | PNG or JPEG, up to **5 MB** |

When an upload is too big, the error names the limit (for example, "has 34 pages. A PDF can have up to 30").

## Videos and editing

| Limit | Value |
| --- | --- |
| Video name | Up to **60** characters |
| AI Editor undo | Last **50** steps |
| Single agent run | Stops after **90** minutes |
| Take control (Agentic Recording) | Up to **10** minutes |
| Viewer comment | Up to **200** characters |

## Templates, assets and Brand Kit

| Limit | Value |
| --- | --- |
| Template instructions | Up to **800** characters |
| Template categories | Up to **5** |
| Assets picked for one video | Up to **10** |
| Pronunciation entries | Up to **500** per workspace  |
| Pronunciation word or phrase | Up to **64** characters  |
| How it should sound | Up to **128** characters  |

## Connectors and sharing

| Limit | Value |
| --- | --- |
| Knowledge base crawl | **50** pages by default, up to **10,000** |
| Select pages list | First **1,000** pages shown |
| Velo MCP connection | Signed in for **30** days from last use |
| Velo MCP upload links | Expire after **30** minutes |
| Velo Public Library code | **6** digits, expires after **10** minutes, **5** tries |
| Velo Public Library sign-in | **30** days |
| Workspace invites | Expire after **7** days |

## Plan limits

- **Free:** One avatar face per billing cycle. Downloaded MP4s carry a watermark. No top-ups, voice clones or custom faces.
- **Seats and credits:** See [usevelo.ai/pricing](https://usevelo.ai/pricing).
