Prompt to Video is a way to create a video message from a single instruction, with no recording, upload, or link required. You describe what you want explained, and an agent researches the topic, writes the script, generates the voiceover, and renders the finished video in one conversation.

<Frame>
  ![Prompt to Video overview](/images/prompt-to-video/overview/01.png)
</Frame>

## How it works

A Prompt to Video session runs as a single agent conversation:

1. **You describe the video.** Type what you want covered — a feature, a workflow, an update for your team — the same way you'd brief a colleague.
2. **The agent reads your knowledge.** It pulls context from any knowledge bases, MCP servers, or connected applications you've linked (see [Connectors](/prompt-to-video/connectors/overview)), so the script reflects your actual product and data instead of generic filler.
3. **It writes a script.** You can review and edit the script before anything is rendered.
4. **It generates a voiceover** using a public voice or your own cloned voice.
5. **It renders the video.** The finished video appears in your workspace like any other videos — shareable, editable, and trackable.

## Where to find it

Start a Prompt to Video session from **New chat → Prompt** in your workspace, or from the dedicated Prompt to Video area in the sidebar.
