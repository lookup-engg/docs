title: "When to use Prompt to Video"
description: "Every path produces a video. The difference is what you start from."
---

Prompt to Video is one of the ways to make a video in Velo. It shares everything the other paths use — workspaces, voice and face clones, libraries, sharing, and [analytics](/creating-a-velo/video-analytics). The only difference is what you start from.

## Start from an asset

Use one of the recording, upload, or link paths when you already have something to work from — a live screen recording, an uploaded video or PDF, or a link to a website or app. Velo turns that existing asset into a narrated video. See [Creating a video](/creating-a-velo/overview) for the available paths.

## Start from a prompt

Use Prompt to Video when you have no asset yet — just an idea of what needs explaining. You describe the video in a sentence or two, and the agent researches, scripts, voices, and renders it for you, pulling in context from your [connected knowledge sources](/prompt-to-video/connectors/overview) along the way.

## Choosing between them

| | Velo | Prompt to Video |
|---|---|---|
| Starting point | A recording, upload, or link | A text prompt |
| Best for | Explaining something that already exists (a demo, a document, a product) | Explaining something you can describe but haven't recorded yet |
| Knowledge sources | The asset you provide | Knowledge bases, MCP servers, and connected applications |
| Editing | Scene-by-scene editor | Prompt-based re-editing, plus the same editor |
| Billing | Velo minutes (shared pool) | Prompt to Video credits (separate pool) |

If you're not sure which to use, ask: do I have something to record or upload, or do I only have something to describe? That answers it.
