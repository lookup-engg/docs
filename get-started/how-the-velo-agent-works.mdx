## How it works

- **One agent for every video:** The same agent handles every way of starting, from a prompt to a recording.
- **It asks first:** Before it starts, the agent asks a few questions in cards, such as audience, footage, theme, length and tone.
- **Nothing is built until you approve:** The agent shows you the plan or script and waits.
- **You can stop it:** Stopping keeps the work done so far.

## Answer the agent's questions

1. Send your request from the home screen.
2. In each question card, choose an answer, or select **Other** and type your own.
3. To let Velo choose, select **Decide for me**. To skip all the questions, select **Decide all for me**.
4. To add material, select **Attach files** in the card.

## Approve the plan

The agent shows its plan, usually as a script you can read scene by scene. Approve it to start the build, or ask for a rewrite. See [Review your script](/create/review-your-script).

## Improve a short request

Before you send, select **Enhance prompt** in the chat box. Velo rewrites your request with more detail. Read it first, because it can add things you didn't ask for.

## Stop the agent

Select **Stop** while the agent is working. It stops, and everything it made so far stays in the chat. Ask it to continue whenever you're ready.

```text
Make a 30-second how-to video on adding a teammate to our workspace, for new admins. Use our Brand Kit.
```

## What to expect

- **Each message uses credits:** Answering questions and approving a script count as messages. See [Plans and pricing](/plans-and-account/plans-and-pricing).
- **Long runs:** A single agent run stops after **90** minutes. If a video seems stuck longer than that, ask the agent to try again.
- **Low balance:** The agent can stop mid-turn if your credits run low. See [When you run out of credits](/plans-and-account/when-you-run-out-of-credits).

## FAQs

**Can I skip the questions?**

Yes. Select **Decide all for me**, and the agent picks sensible answers.

**Does the agent make anything before I approve?**

No. It waits for you to approve the plan before it builds the video.

**If I stop the agent, do I lose my work?**

No. Everything made before you stopped is kept.
