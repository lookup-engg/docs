## How it works

- **Shared files:** Everything in the Asset Library is shared with your whole workspace.
- **Summaries:** Velo summarizes each file, so it can suggest the right ones. Anyone can edit a summary.
- **Suggested in new videos:** Velo asks which assets to use before it writes the script.

## Upload a file

1. In the sidebar, select **Assets**.
2. Upload your file.
3. Check the summary Velo writes, and edit it if it misses something.

If Velo can't read a file, you'll see **Couldn't read this file.** Select **Try again**.

## Use assets in a new video

1. Start a new video and send your request.
2. When Velo asks **Which assets would you like to use?**, tick up to **10** files, or select **Don't use any**.
3. Continue to the script.

Velo doesn't ask for **Record Yourself** or videos built straight from a recording.

## Replace a file and update your videos

When a logo, price or screenshot changes, change it once and update every video that uses it.

1. In **Assets**, find the file and select **Replace**.
2. Upload the newer version.
3. Find the videos marked as outdated.
4. Select **Regenerate**, and pick the outdated videos to update.

Videos already using the old file keep it until you regenerate them.

## Good to know

- **Formats:** Documents, images, video, audio and HTML. The Asset Library doesn't take old .ppt or .xls files, or fonts. See [Supported formats](/help/supported-formats).
- **Documents vs media:** Documents are sources for Velo's script. Images, video and audio can also go on the timeline.
- **Edited summaries stay:** Velo never overwrites a summary someone edited.
- **Deleting:** The person who uploaded a file, an admin or an owner can delete it. Videos already made with it don't change.

## FAQs

**Who can see our assets?**

Everyone in your workspace.

**Does uploading use credits?**

No. Uploading files and their summaries don't use credits.

**Can I skip the asset question?**

Yes. Select **Don't use any**.
