## Connect an application

1. In the sidebar, select **Connectors**, then **Applications**.
2. Find the app: search, or browse **Popular** and **View All**.
3. Open the app and connect it with your account for that tool.

Apps you haven't set up show **Not connected**. **Connected** lists the ones you've authorized.

## Access

- **Your own account:** Each app connects with your account and pulls only data you can already see.
- **Disconnect:** Disconnect an app at any time from **Applications**.

## FAQs

**Which apps are available?**

The **Applications** tab is the current list. Search it for your tool.

**Can Velo see data I can't?**

No. It uses your access in each app.

**My app isn't listed. What do I do?**

If you run your own MCP server for it, connect that instead. See [MCP servers](/connect/mcp-servers).
